## 生产公式

1. 年/月/时至少透一枚克泄耗干，才允许进入耗方群势。
2. 只检查年/日/时完全相同的重复地支；按藏干层级权×泄耗克类别权计算原始量。
3. 重复支本气同类透干时只乘 echo 1.75，否则只乘 repeat 0.4；两者互斥。
4. 冲根只处理冲及月柱的非库六冲；只折正值 `得令+长生`。生效 0.5，减力/被解 0，多关系封顶 100%。
5. 总分改为七项：`得令 + 长生 + 得地 + 得势 + 会局 + 耗方群势 + 冲根修正`。
