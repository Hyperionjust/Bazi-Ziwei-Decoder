# bazi-ziwei v3.11.0 变更摘要（造化元钥吸收工程）

> 主线：**吸收 ≠ 校对**。此前调候层只知道每格「取干两个字」，这一版把《穷通宝鉴》/《造化元钥》每格的**条件树**搬进算法层——
> 全表 **120 格 / 1396 条条例**，每条「若」用受控词表写成机器可判形式，同盘可复现；档位照录典籍、解读层反同质化展开。
> 同批结清 v3.10.0「已知问题」全部四条（S1-1~S1-4）、韦千里典籍命例入库（S2）、置信度四维与引爆窗口（S3）。
> 底线全程遵守：**排盘算法层一字未动、`取干` 表一字未动**、流派只改解读不改排盘、幕后台前分离、dist-bundle 零安装。

> **版本断档说明**：v3.9.1 与本版之间的 v3.10.0（顺逆双轴、调候表外置+快照锁、双系校勘等）未单独出包发版，
> 其内容与流水由 `CHANGELOG.md` 对应段承接，并随本版一并入包；release-notes 不逐版补写。
