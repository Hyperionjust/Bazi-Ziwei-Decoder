# bazi-ziwei v4.0.0 变更摘要

> 主线：把八字海报从“专业数据一次铺满”重构为“先认出自己的八字，再读现实结论，最后按需核对专业依据”。本次以产品体验的大幅升级进入 4.0；排盘 CLI、既有 analysis schema 与旧 chart/analysis 兼容路径不作破坏性变更。

## 项目定位与署名

**原创主导。** Bazi-Ziwei-Decoder 由 Hyperionjust 独立主导设计、开发与维护。当前产品架构、增强与校准体系、AI 对话工作流、质量门禁、解读规范、发布工程，以及四套现行海报的信息架构与视觉系统，均在本仓库中独立新增或实质重构。4.0 起，README、英文文档、包内元数据与海报页脚统一展示 `Bazi-Ziwei-Decoder / Hyperionjust`，不再使用“魔改版”作为产品身份。

**合规保留。** 早期 `dzcmemory-web / bazi-ziwei-skill` 基线、Yiqi 排盘内核和 `lunar-typescript` 的来源信息集中放在致谢、`NOTICE` 与 `LICENSE`；保留应有 credit，但不再覆盖当前项目的原创主叙事。

## 阅读路径

- 标题之后先显示年、月、日、时四柱本体，并突出代表本人的日柱与日主五行。
- 总领使用与正文 01—08 一一对应的八项人生坐标；八张卡同尺寸、同字号、同水印尺度，可直接跳到相应章节。
- 性格、事业、感情、健康、关系变化、近年节奏、人生阶段与日常行动全部前置。
- 完整四柱详表、藏干、十神、旺衰、五行、格局、用神、大运流年和神煞统一放到“专业依据”之后。

## 内容与可读性

- 对话入口把长注意事项压成极简声明和“底色／长板／提醒／阶段”四个本人结论；下钻以加粗要点和小段落为主，减少连续 bullet list。
- 当用户询问交付形态时，强烈推荐先和 AI 聊一轮详细分析、确认重点后再做海报；仍保留直接海报和同轮完成的选择。
- 四大现实解读、三个精读段、十神白话与相关说明由渲染层按完整句义整理为每 2—3 句一段，并保护绿色／红色内联高亮标签。
- 所有正向或偏正向语义逐处使用绿色粗体；正负混合句拆开着色。十神白话升级为与四大解读同等级的完整长段。
- “未来几年怎么走”只在主区显示最多四张白话年份卡，回答年份、节奏和行动；完整运岁引动记录后置折叠。

## 视觉系统

- 总领采用骨白宣纸与极浅五行洗色，不再使用深蓝整块、点阵麻纹或固定偏绿背景。
- 主题按日主木、火、土、金、水自动切换，并同时进入大面积浅洗色、圆环、细线、编号和边框。
- 正文色块使用透明渐变、浅水纹、开口圆环和低透明汉字水印，不铺纯色。
- 八张总领卡进入单一等轨网格；标题字级全面高于正文。桌面样例八卡统一为 235×167，390px 下统一为 160×186。

## 确定性能力展示

- 新增调候“典出”、裁决／轴冲突“核心看点”、时间轴 `⏳` 引爆标记、十二节气月风向条，以及大运／流年的护体强中弱第二维。
- 新增独立“罕见现象”板块：算法列出现象名、罕见度与涉及柱，解读层说明偏正向、偏提醒或两面性，并给出现实落点与行动。
- 上述确定性块由 `chart.json → render.ts` 直出，不要求 LLM 复述结构字段；无数据时零 DOM。

## 兼容与验收

- 旧 analysis 缺新版八项坐标时仍显示四柱身份锚点，不渲染半套坐标；旧 chart、无 analysis 与缺可选算法块均可继续渲染。
- 1440px 与 390px 均无横向溢出、空卡或残留占位符；八个坐标链接全部命中唯一正文目标。
- TypeScript 构建、五个 `dist-bundle`、18 个回归入口、四类金标样本和 source↔bundle 逐字一致性全部通过。

完整实现与验收记录见 `docs/工单-v3.14-八字海报v2.md`。
