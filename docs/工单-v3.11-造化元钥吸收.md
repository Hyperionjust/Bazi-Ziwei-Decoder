## 二、主线 M · 造化元钥吸收工程设计

### 2.1 目标重定义：吸收 ≠ 校对

校对（已做的）只回答「取干列表抄没抄错」。**吸收**要把书里真正值钱的东西搬进算法与解读——
书的每一格不是「丙癸」两个字，而是一棵**条件树**：

> 正月甲木：得丙癸透，富贵双全（上）；癸藏丙透，名寒木向阳，主大富贵（上）；
> 倘风水不及，亦不失儒林俊秀（中）；如无丙癸，平常人也（下）；
> 一派庚辛，主一生劳苦，克子刑妻（忌）；一派壬癸又无戊己制，名水泛木浮（忌）；
> 一派戊己支会金局，为财多身弱，富屋贫人（忌）……

现在 skill 只知道第一行的两个字。**丢掉的条件分支恰恰是确定性可判的**——丙透没透、癸藏没藏、
是不是一派庚辛，全部是算法层查盘面就能判的事实。这就是进化空间。

### 2.2 产出形态：tiaohou.json v2（每格从数组升级为条例对象）

```json
"甲/寅": {
  "取干": ["丙", "癸"],
  "条例": [
    { "若": "丙癸双透",            "则": "富贵双全",               "档": "上" },
    { "若": "癸藏支且丙透干",       "则": "寒木向阳,主大富贵",       "档": "上", "名": "寒木向阳", "意象": "早春寒木得暖阳,得势而发" },
    { "若": "无丙无癸",            "则": "平常人也",               "档": "下" },
    { "若": "庚辛成一派",          "则": "一生劳苦,克子刑妻",       "档": "忌" },
    { "若": "壬癸成一派且无戊己",   "则": "水泛木浮",               "档": "忌", "名": "水泛木浮", "意象": "水多无堤,根基漂浮" }
  ],
  "病": [],
  "原文": "…全文引…", "出处": "…", "级别": "佐证"
}
```

> `意象` 是概念级素材（比喻的核心，不是句子），供层3 解读自由展开用；`则` 是典籍原判，照录不改写。

`若` 字段用**受控词表**写（透干/藏支/成一派/支会局/无X/有X制…），保证机器可判——这是整个设计的命门：
条件必须写成算法层能对盘面求值的形式，不能是散文。`病` 字段承接「癸水一见，泄庚湿甲伤丁，故以癸为病」类内容。

**受控词表的管辖边界（作者拍板 2026-07-29）——三层分离，只有第一层受控：**

| 层 | 内容 | 约束 |
|---|---|---|
| 层1 · 盘面判定 | 「若」：丙透没透、是不是一派庚辛 | **受控词表**，机器求值，同盘可复现 |
| 层2 · 典籍论断 | 「则」+「名」+「原文」：富贵双全 / 寒木向阳 | **照录原文**，是数据不是输出 |
| 层3 · 用户解读 | 这对眼前这个人意味着什么 | **自由**。硬约束仅两条：①不得引用未命中的条例名（防编造）②档位不得写成宿命断语（护栏） |

层3 的反同质化是**设计要求**：同一条例在不同盘上的呈现，必须结合该盘的格局/十神结构/当前大运语境重写——
「寒木向阳」在一个食伤旺的盘里可以讲创作端的舒展，在一个官杀重的盘里可以讲被赏识的通道，措辞、切入角度、
落到事业还是心态，全部由 LLM 按盘定。**严禁**在提示词里为任何条例配固定白话句式——v3.7.1 的教训
（正缘画像单一句式 → 全盘同款文案）就是这么来的。schema 里给的是 `意象` 字段（概念级素材，如「早春寒木待暖」），
不是句子模板；评审遍（bazi-poster-review）负责查「条例呈现是否结合了本盘语境」这一语义项，脚本层不管措辞。

### 2.4 工作路径：知砚斋打底 + 影印本校勘（不逐页抄影印本）

影印本 464 书页逐页视觉读不划算（约 200+ 次读取，跨多个会话，转录劳动大于校勘价值）。改为：

1. **知砚斋电子本（78% 覆盖）程序化抽条例初稿** —— 有文本层，条件句式规整（或/若/如/一派/得），可半自动切分；
2. **人工復核每格条例**（这是编辑判断，不可省）；
3. **影印本按格抽查（作者要求加量）**：每行抽 **4~5 格**视觉核对 + 27 个知砚斋缺失格全部用影印本视觉补——
   合计约 70 格有影印本背书（近六成），且每行必含「条例最多的格」与「与知砚斋本有出入的格」；
4. 每格标注来源与校勘级别，快照锁重新祝福。

### 2.6 边界（先说清楚，防跑偏）

- **吸收 ≠ 全信**：条例照录典籍，档位（上/中/下/忌）是书的判断不是我们的实证。解读层引用时措辞仍守顺逆/可证伪护栏，「主大富贵」这类断语转写为倾向性表述。
- **两系差异**：遇知砚斋本与影印本条例冲突的格，两版并存标「⚖两系分歧」，不擅自择一。
- **评注与语译**（影印本的徐乐吾评注/李铁笔语译层）**本轮不吸收**，只吸收原文条例。评注是二级材料，等原文层稳了再议。
