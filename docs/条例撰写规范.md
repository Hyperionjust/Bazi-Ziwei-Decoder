# 条例撰写规范（造化元钥吸收工程 · 每批照此办理）

> 立于 M2（乙/丙/丁 三行），M3 起沿用。改规范请连同 `calculator/bazi-enrich/tiaohou-tiaoli.ts`
> 的 `谓词表` 与 `calculator/tiaohou.json` 的 `_词表` 一起改——测试会强制三处对齐。

工程背景：把《穷通宝鉴》/《造化元钥》每格从「取干两个字」升级为**条件树**。
书里真正值钱的是条件分支——「一派庚辛，主一生劳苦克子刑妻」「支成木局，得庚为贵，无庚必凶」——
这些恰恰是**盘面可确定判断**的事实。你要做的就是把它们翻译成受控 DSL。

M1/M2 已完成 48 格 537 条（甲乙丙丁），可作范例：`calculator/tiaohou.json` 的 `条例` 块。
**动手前先读那里的 `甲/寅`、`甲/丑`、`甲/酉` 三格**，照着写。

## 一、产出物

一段 **Python 源码片段**，形如 M1 的 `build_tiaoli.py`（在 生成脚本，随批次放在临时工作目录；tiaohou.json 里的成品才是事实源）。
每格一个 `CELLS["X/Y"] = dict(...)`，字段：

```python
CELLS["乙/寅"] = dict(

  原文="…本格全文，见下「原文规则」…",
  影印本抽查=dict(书页="NN(PDF MM)", 结论="一致 / ⚖ 分歧 / 大体一致·措辞有出入", 记录="…"),   # 只有抽查过的格才写
  两系分歧=[dict(条例="id", 穷通宝鉴系="…", 造化元钥系="…", 说明="…")],                        # 有分歧才写
  条例=[
    dict(id="乙寅-丙癸两透", 名="丙癸两透", 若="透:丙 且 透:癸", 则="丙癸两透，科甲定然", 档="上",
         意象="早春芝兰得暖阳又得润"),
    ...
  ],
  病=[dict(字="癸", 依据="…原文里明说 X 为病的那句…", 出处=ZY)],   # 没有就 病=[]
)
```

## 二、受控词表（层1，只有这一层受控）

`若` 只能用这些谓词，**词表外的写法会在 `npm test` 直接 FAIL**：

| 谓词 | 参数 | 语义 |
|---|---|---|
| `透:X` | 天干 | X 出现在四柱天干（含日干） |
| `藏:X` | 天干 | X 出现在四支藏干（本/中/余气任一） |
| `有:X` | 天干 | 透 或 藏 |
| `无:X` | 天干 | 非「有」，全盘不见 |
| `制:X` | 天干 | 等同「有」，对应典籍「有X制之」 |
| `支:Z` | 地支 | Z 出现在四支 |
| `支五行:W` | 五行 | 地支字面五行为 W 的支 |
| `会局:W` | 五行 | 四支成三合/半合/三会/半会该五行局；土局特指辰戌丑未≥3 |
| `成派:XY` | 同五行天干组 | 「一派X」。加权分≥3.0 且至少一字透干，**不含日干本身** |
| `十神:S` | 十神/十神类 | 四柱（不含日干本身）天干+藏干中有该十神。类：比劫/食伤/财/官杀/印 |
| `十神透:S` | 同上 | 只看天干——对应原文明说「干透比劫」这类 |

- **计数写法**：谓词加「数」缀 + 比较式：`透数:丙>=2`、`有数:癸>=2`、`十神数:比劫>=2`、`支五行数:水>=2`。比较符 `>= > = <= <`。`无/制/会局/成派` 不可计数。
- **组合子**：`且`（AND）`或`（OR）`非`（NOT）+ 括号。优先级 `非 > 且 > 或`。
- 写法要有空格：`透:丙 且 透:癸`、`会局:金 且 (透:庚 或 透:辛)`。

## 三、六条硬规则（违反任何一条测试会 FAIL）

### 1. `则` 必须是本格 `原文` 的**连续片段**（照录，一字不改）
标点会被归一化，但**不能跨 `／` 拼接边界**。这是「层2 照录不改写」的机器护栏——
**吸收 ≠ 转述**。想写「此人聪明」而原文写「主聪明雅秀」，就得照抄后者。

### 2. 不许有死条例
月令藏干是**恒定**的。把「无丙」照字面写成 `无:丙`，在寅月**永远为假**（寅恒藏丙）。
常见坑：寅藏丙戊 / 辰藏癸 / 巳藏庚 / 申藏庚壬戊 / 午藏丁 / 戌藏戊 / 未藏丁乙 / 丑藏癸辛 / 亥藏甲。
→ 这种情况按 **`非 透:X`** 判，并写 `判定备注` 说清为什么偏离字面。

### 3. 不许有恒真条例
反方向同理：「须见戊土」在申月写成 `有:戊` 就**永远为真**，条件等于没判。
→ 同样按天干口径判 + `判定备注`。
**写完自己心算一遍**：这条在本月支下会不会恒真/恒假？

### 4. `名` 必填、格内唯一
它是防编造的句柄（体检器要查「解读引用的条例名是否在命中清单里」）。2~5 字，取典籍原有名目优先
（如「木秀火明」「藤萝系甲」「去浊留清」），没有就自拟一个贴切的。

### 5. `意象` 必填，是**概念级素材不是句子模板**
写比喻的核心，不写成品文案。好：「早春寒木得暖阳，根下有润」。
坏：「你的人生就像一棵向阳生长的树」。严禁写成可直接粘贴给用户的白话句。10~20 字。

### 6. `档` 只有 上/中/下/忌
- 上 = 富贵双全/科甲/大富贵/上上之格
- 中 = 秀才/小贵/异途/富中取贵/技艺之流
- 下 = 平常人/常人/庸人/贫贱/寒儒/僧道/下格
- 忌 = 劳苦/刑妻克子/残疾/夭折/贫夭/大奸大诈

## 四、原文规则

- 从 知砚斋本文本层（`pdftotext -layout 素材/穷通宝鉴.pdf`）取，**逐字照抄**。
- PDF 换行造成的空格要去掉；原文里的全角逗号句号保留。
- 若本格原文由**不相邻**的几段拼成（如季度总论 + 逐月条），**必须用 `／` 分隔**，不许用句号直接缝。
- 季度总论里明确适用于本月的句子可以并进来；纯属别月的不要并。
- 若几个月共用一段（如「五六月乙木…」），该段写进两格，条例 id 用共同前缀并加 `适用="五六月共段"`。

## 五、影印本抽查（每行 4~5 格）

素材：`素材/xzb2100653 李铁笔-造化元钥评注.pdf`（无文本层，纯影印，须视觉读）。

- **页码换算**：`PDF 页 = (书页 + 4) / 2`。一个 PDF 页是一个对开，**右页为小号、左页为大号**（右起竖排）。
- **先定位本行在哪几页**（别一页页翻）：影印本每个左页的最左侧竖排印着「第N節 三春X木總論」和页码。
  把这一竖条从几十页里裁出来拼成一张长图，一次读图就能把整本的节次-页码对照表拿到手：
  ```bash
  pdftoppm -f <起> -l <止> -r 100 -jpeg -jpegopt quality=55 "<pdf>" /tmp/yy/p
  python3 -c "
  from PIL import Image; import glob
  fs=sorted(glob.glob('/tmp/yy/p-*.jpg')); crops=[Image.open(f).convert('L').crop((30,120,108,700)) for f in fs]
  W=sum(c.width for c in crops); out=Image.new('L',(W,max(c.height for c in crops)+10),255)
  x=0
  for c in crops: out.paste(c,(x,5)); x+=c.width
  out.save('/tmp/strip.png')"
  ```
  然后 Read `/tmp/strip.png`。一张图别超过 50 页，否则字太小。
- **各行页段（PDF 页）**：辛 **171-193** / 壬 **194-211** / 癸 **212-229**（M4 实测回填，230+ 为结论/编后语/版权页，正文到 229 止）；
  戊 ~124-143 / 己 ~143-160 / 庚 ~160-178（甲乙丙丁实测外推，M3 抽查时未见明显偏差；再用时以各格「影印本抽查.书页」记录为准，或用上面的条带核实）。
- 渲染命令（写到可写目录，如 `/tmp`）：
  ```bash
  pdftoppm -f <起> -l <止> -r 110 -jpeg "<pdf路径>" /tmp/yy/p
  ```
  然后用 Read 工具读 jpg。110 dpi 的对开图可读。
- 版面：`【原文】`段是要核的；`【評註】`（徐乐吾）与`【語譯】`（李铁笔）**本轮不吸收**，跳过。
- 每行挑 4~5 格，**必须包含「条例最多的格」**，其余尽量跨四季分布。
- 逐格给结论：`一致` / `大体一致·措辞有出入` / `⚖ 分歧`。
- **发现分歧不要择一**：两版并存，写进 `两系分歧` 字段和对应条例的 `两系分歧` 内联字段。

## 六、`病` 字段（M2 的重头，J2 护体线要用）

原文里**明说某字为「病」**的，登记进 `病=[dict(字="癸", 依据="原句", 出处=ZY)]`。
必须是原文明指，不要自己推断。已知的例：
- 丁/巳：「癸水一见，泄庚、湿甲、伤丁，故以癸为病」→ 病:癸 ★这是 M2 的验收点，务必登记
- 三秋乙木：「惟九月端用癸水，恐丙暖戊土为病也」→ 乙/戌 病:丙（注意读清楚是谁为病）

`依据` 也要照录原文。

## 七、交付格式

直接给出可粘贴的 Python 代码块（`CELLS[...] = dict(...)` 若干个），外加一段简短报告：
1. 每格条例条数
2. 影印本抽查了哪几格、书页号、各自结论
3. 发现的两系分歧（原文对照）
4. 登记的 `病`
5. 你拿不准的地方（宁可标出来也不要糊过去）

### 写完必做三件事（顺序不能乱）

1. `cd calculator && npx tsx fixtures/bless-tiaoli-relations.ts` —— 回写 `关系`/`蕴含`。
   **每次重跑生成脚本都会冲掉这两个字段，必须重新 bless**，否则测试 ⓖ 会 FAIL。
2. `npm test` —— 全绿；条例快照会 FAIL 一次，把实际 hash 填回 `EXPECTED_TIAOLI_HASH` 即为祝福。
3. `npm run bundle` —— 改过任何 `.ts` 都要重打包，`dist-bundle/` 是入库产物。

### 已知的坑（每批都会踩，先看一眼）

- **日干本身在天干上**：`透:<日干>` 恒真、`无:<日干>` 恒假。原文「四柱多丙」「见丁比出干」这类
  一律改判 `透数:X>=2` 或 `十神透:比劫`（求值器排除日干）并留 `判定备注`。丙行丁行都踩过。
- **受控词表没有柱位谓词**（「时月两透」「生庚子时」「年支见子」）。只能近似 + 留备注。
  若某一行这类句子多到没法忍，可提议加 `柱透:年/月/时:X`——但那是改词表版本，要单独拍板。
- **`成派` 排除日干**：「一派」说的是日主周围的势。同气成派（`成派:甲乙` 对乙日主）尤其要注意。
- **`病` 只登记原文明说「为病」的**。丙火行全篇一个「病」字都没有——那是文献事实，不是漏抽。
