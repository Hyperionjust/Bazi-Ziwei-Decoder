## 二、批次设计（每批一个新会话，先F后G——海报要呈现的正是旺衰修完后的判定）

### 批F · 旺衰 v3（修 4✗；≈1 会话，风格照批A：金标网格联调，不拍脑袋）

- **F1 耗方群势入分**：得地/得势镜像出负向项——克泄耗方（财/官杀/食伤）的地支本气根与会局按对应负系数扣分（系数联调定值，起点建议为帮身系数的 0.5~0.7 倍——月令已扣过一次，防重复计罚须用「月令之外」口径）。
- **F2 冲根减分**：被六冲且无解（复用 `adjudicateInteractions` 裁决结果——**生效**的冲才减，被解/减力不减或减半）的根气/会局，其加分打折或归零。阮例「两亥冲巳印根」是验收主证。
- **F3 调候弱标记**：不入扶抑总分（两轴硬合会把分数搅浑），出独立字段 `调候性弱`（寒湿/燥烈判定，从调候取干与盘面湿燥比对得出），出口与解读层按「体感之弱」并陈——郑例验收：扶抑分可仍为正，但盘面必须出现调候性弱标记且解读按弱侧措辞。
- **验收**：22 例对照 4✗ 目标 **≥3 翻正**、14✅ **零回退**（断言锁）；4◐ 复查记录；200 盘 low 率哨兵区间复校（计分变了分布会动，区间按新联调结果重设并留痕）；13 项全绿；三份样例 diff 逐行核。

### 批G · 八字海报 v2（拆三个会话批次，设计→实现→门禁）

- **G1 设计批（纸面定稿，不动代码）**：新增区块清单与版式草图（建议新增：①「典出」条例引用块 ②裁决/轴冲突「一句话看点」徽章区 ③timeline ⏳标记 ④流月风向条[条件项] ⑤运岁条体档第二维）；`analysis` schema v2 字段定稿（新字段全部**可缺省**——旧 analysis 渲染不崩，兼容是硬约束）；`spec.json` 规格草案（各新块句数/字数/着色规则）；评审遍与体检器新增校验点清单。产出=设计文档入 docs/，作者过目后 G2 才动手。
- **G2 实现批**：模板 HTML 重构 + `render.ts` 注入接线（算法侧数据全部现成：条例命中/裁决/轴冲突/引爆窗口/流月都在 chart.json 里，本批只做「取出来摆上去」）+ `bazi-poster.md` 提示词按新 schema 改写（产出规则含分维取档措辞）。
- **G3 门禁批**：`check-analysis.ts` 新块体检规则（条例引用位与 J4 打通——引用块里的条例名必须在命中清单，比现在扫全文更精确）+ `check-template.ts` 新模板门禁 + `bazi-poster-review.md` 评审项 + **金标样例重制**（qa 质检盘正好特性全覆盖，建议用它做新金标底盘）+ `test-golden` 全绿。
- **验收（G 整体）**：新旧 analysis 双向渲染不崩；质检盘海报肉眼过版（作者本机浏览器）；四件套同步性由 `test-spec-sync` 哨兵锁住。
