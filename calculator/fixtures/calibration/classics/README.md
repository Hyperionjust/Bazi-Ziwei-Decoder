# 典籍命例库 · classics（S2 韦千里试点）

> `case_type: 典籍判定` 命例：金标是**书上的判定**，不是生平事件；不含隐私，入库当回归。
> 首批 7 例取自韦千里《批命104例》应运篇（素材/批命104例…pdf），选断语最完整、
> 且以**官杀主题为主**——这是 S1-3（格局相神改法）点名要的对照集。

## 命例怎么来的（可复现）

1. 书载生辰行（蒋介石/阎锡山）直接农历→公历；无生辰行的由书载四柱在该年干支窗口内
   反推公历日时（用与排盘同源的 lunar-typescript 搜索，唯一解）。
2. **每例都以 run-chart 复现书中四柱为准入条件**（7/7 ✅）；其中 5 例反推日期与史载生日
   互证一致，吴佩孚差一天系子时跨界、宋子文系书载四柱本身与史载生日不合（书末自注有异文）。
3. 金标（`classic.韦氏判定`）只从断语原文提炼，**算法层输出不写进命例文件**——
   金标是书，算法是被校的一方，算法每改一版都可拿同一批金标重跑对照。

## 试点对照表（算法层快照 2026-07-30 · v3.11-dev M4 后；重跑命令见文末）

| 例 | 韦氏金标 | 算法层（扶抑 / 调候 / 格局 / 共识） | 对照结论 |
|---|---|---|---|
| 阎锡山 | 杀重身轻；癸**印**化杀＋丁**食**制杀 | 偏弱；水木 / 癸丁丙 / 七杀取火水 / 共识**水** | ✅ **高度一致**（癸+丁 正是调候前两字） |
| 马占山 | 病于水盛；用丁**火**印，喜乙木资印 | 偏弱；火土 / 丙甲戊 / 正官取水火 / 共识**火** | ✅ 一致 |
| 许世英 | 众谓从杀，韦断**不从**；身弱用**印(水)** | 极弱(可能从弱)、⚖从格分歧显式并陈；共识**水** | ✅ 一致，且算法把韦文核心议题标成显式分歧 |
| 吴佩孚 | 杀重贵制化；乏**金**制杀、乏**火**印化杀为病 | 偏旺；金水木·忌火土 / 格局取木金 / 共识木 | ◐ 部分一致（金同；火被扶抑忌压掉） |
| 梅兰芳 | 木火太旺；喜酉**金**癸**水**（财杀清粹） | **中和**(-0.1)；调候甲庚戊 / 伤官取木金 / 共识木金 | ◐ 部分一致（金同、水缺；旺衰判定相左） |
| 宋子文 | 财旺身弱；喜**帮身**，忌财愈重 | 偏弱(低置信)；扶抑**土金**✓ / 但`出口.开运用神`取了发用线的**水** | ◐ 护体线一致、**出口相左** ⭐S1-3 相关 |
| 蒋介石 | 伤官佩印：用**火**印制伤，**不必再见伤食** | 偏旺；扶抑取**金**水木、**忌火** / 共识木 | ✗ **方向相反** ⭐S1-3 主证 |

**试点结论（供 S1-3 开工用）**：

- 7 例中 3 例一致、2 例部分一致、2 例实质分歧。分歧的共同形状与工单 S1-3 的预判吻合：
  **格局相神（蒋之火印、吴之火印、宋之帮身）被扶抑线的忌神清单压倒**——扶抑按旺衰一刀切
  「身旺忌印比」，而韦氏在伤官旺/杀重的盘上恰恰以印为相神。
- 蒋介石例最典型：韦明言「运喜逢印，不必再见伤食」，算法层却「忌火、取金(伤食)」，
  且其应期断语（丙午运火候功深/甲辰运伤官见官宜退）全部押在印与伤食的向背上，可直接
  用作 S1-3 改法的验收点。
- 阎锡山/许世英两例证明：**身弱侧的杀格算法层已经对**（印化杀与从格之辨都在），S1-3
  要动的只是**身旺侧**「格局相神 vs 扶抑忌」的裁决权，别把对的一半改坏。
