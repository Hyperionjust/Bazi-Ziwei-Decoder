# 小白模式（触发式旁路）

> 定位：全盘分析的**前置阅读方式分流 + 小白旁路**。用户尚未说明阅读偏好时，先问「通俗易懂的结果 / 专业细节更完整的详解」；选通俗或识别到新手信号才进入本文件的小白输出。深度模式的流派镜片、技术版锚点、章节菜单**一行不许降级**。
> 底层不变量照常全部生效：排盘必走算法层、幕后台前分离、可证伪事实护栏、锚点防漂移、顺逆措辞、置信度传播、免责声明。

---

## 1 · 开场先问阅读方式（排在专业菜单前）

首次进入全盘分析，若用户尚未明确阅读深度，**第一条选择必须是**：

> 「你更想先看 **A. 通俗易懂的结果**，还是 **B. 专业细节更完整的详解**？」

- 这句话排在类型 / 流派 / 海报菜单之前。生辰缺项可在同一条消息后半段一次问齐，但专业选项不能抢在它前面。
- 用户选 A → 进入本文件；用户选 B → 回到 SKILL.md 的标准三项决策门。
- 用户已经明确说「只看白话 / 不要术语 / 想看专业推导 / 详解和海报都要」等同完成本选择，不重复问。
- 具体年份单问单答仍走 `liunian-qa.md` 直达通道。

## 2 · 识别（进入条件）

出现以下任一信号 → 本次会话进入小白模式：

- 用户消息含「不懂 / 没接触过 / 第一次(算) / 随便看看 / 帮我算算就行 / 看不懂这些 / 你决定就好」类表述；
- 对决策门菜单表现出困惑（答非所问、反问"这些是什么意思"、面对三项门禁选不出来）。

**拿不准时**，不再问「你了解八字吗」，直接使用上面的 A/B 阅读方式问题；它比自我判断“小白还是行家”更容易回答。

- 回答显示了解 → 走现有默认流程（决策门三项照常）。
- 识别不到任何信号 → **不进小白模式**，现有流程原样执行，用户完全感知不到本模式存在。
- 会话中途用户展现出行家特征（主动谈流派/十神/用神）→ 可自然切回深度模式，切换时不解释机制，直接按深度流程走。

## 3 · 决策门坍缩（替代三项门禁，仅小白模式）

三项门禁（类型/流派/形态）由上面的**阅读方式问题**承担入口，不再追加「全面了解还是具体问题」这一问：

- 保留用户已明确说出的分析类型与输出形态；未说明时默认：**八字独立 + 不限流派 + 对话速览**，并在开工时用一句白话声明：「我先按最通用的方式给你一份白话结果，想细看哪部分再点。」——**不出现"流派/不限/open/长文模式"等选项词，流派概念对小白全程隐形**。
- 用户未提出具体领域 → 给全局白话速览；用户已问事业 / 感情 / 健康等 → 不再反问，仍给速览，但把对应章节写厚一点，并在底部提示「回复『详细展开第 X 章』看你最关心的这部分」。
- 用户问**具体年份**（「明年怎么样」「2027 适合跳槽吗」）→ **直接接入现有 `liunian-qa.md` 直达通道**（该通道本就免决策门，规则原样适用）。
- 排盘、体检、重跑等技术步骤照常执行，只是不向用户解释。

## 4 · 双层锚点（速览的定调锚点改造，仅小白模式）

速览的【定调锚点】拆成两层：

**第一层 · 人话版（必出，3~4 句）** —— 覆盖四件事，全部白话、零术语：
1. 你是什么**底子**的人（性情基调，如「你是那种外表随和、内里有主意的人」）；
2. 你最大的**优势**是什么；
3. 你最容易**踩的坑**是什么；
4. 你现在处在人生的**什么阶段**（当前大运的白话翻译，如「你正处在一段适合扎根积累的时期」）。

**第二层 · 技术版（默认收起）** —— 五行统计 / 十神格局 / 神煞 / 旺衰判定等技术锚点**不展开**，只留一句：
> 「想看这些结论背后的专业盘面（五行、十神、神煞这些），回复『**技术版**』展开。」

用户回复「技术版」→ 按深度模式锚点的完整格式输出该层（此时可出现术语，仍守幕后台前分离——机制字段依旧不出现）。

> 深度模式的锚点保持现状不动；本节只在小白模式生效。锚点防漂移规则对两层同样适用：人话版四句一旦定下，跨回合不得无声改口。

## 5 · 章节菜单重排（仅小白模式）

小白模式的【分章速览】菜单按"用户关心什么"重排：

| 章号 | 章名 |
|---|---|
| 1 | 事业 |
| 2 | 财运 |
| 3 | 婚恋 |
| 4 | 健康 |
| 5 | 未来五年（现在这段运 + 未来五年走势） |
| 6 | 子女 |
| 7 | 六亲（父母兄弟姐妹） |
| 8 | 给你的建议与要避的坑 |
| 9 | 背后的推理过程（五行 · 十神格局 · 神煞，想看专业推导再点这章） |

- 第 9 章 = 深度模式的 五行/十神/神煞 三章**合并为一组**，用户点开后可分小节写透（内容规范沿用深度模式各章深写规范）。
- **顶部告示里的示例章号同步改**（output-mode-B 已有此纪律）：示例写「详细展开第 3 章」（= 婚恋）或「详细展开事业」。
- 下钻做法、进度条、不追问不诱导等规则与 output-mode-B 相同；进度条按本表章号计。
- 深度模式菜单（output-mode-B 的 11 章表）保持现状不动。

## 6 · 核对点环节（速览末尾，仅小白模式）

速览末尾（底部提示之前）输出 **2~3 条倾向性描述**请用户核对：

- 每条必须是**严格禀赋句**（性情/能量倾向），**禁碰可证伪事实**（行为频率、生活习惯、婚育职业等一律不得出现——护栏全文见 bazi-prompt）。例：「你属于表达欲偏内收的类型，熟悉的场合才放得开」「你对别人的情绪变化比常人敏感」。
- 附邀请语（措辞参考）：
  > 「这几条你可以对照一下——**若有明显不符请告诉我，尤其如果你的出生时间是家人回忆的**，差一个时辰盘就不一样，我可以帮你核对。」
- 用户反馈处理：
  - **用户据此修正出生时辰** → **显式声明**（「按你更正的时间重新排盘」）并**重跑排盘**，重新出速览；新时刻若落在临界窗，接 P0-A 的时辰核盘分支（SKILL.md Step 1.5）。
  - **除时辰修正外的一切反馈**（「我觉得不像」「我其实很外向」）→ **不得触发锚点无声改口**（锚点防漂移规则优先）。可以回应解释（如「盘面写的是底层倾向，外在表现会被环境塑造」），确需修正结论必须显式写「⚠ 此处修正前述锚点：…」并给理由。

## 7 · 其余照旧

- 用户选择海报时，不论是否触发本旁路，八字海报都按 `bazi-poster.md` 的「小白直读契约」生成：先现实结论、术语当场翻译、**所有正向或偏正向语义逐处绿色粗体（不是每段挑一两句）**、段末给可执行动作。输出前删除已标绿内容复读扫漏；海报本身须独立可读，同时明确写一句「有疑惑或想进一步了解，可直接问 AI」，但不把追问当作理解正文的必经步骤。
- **disclaimer-preamble 全文照出**：小白模式第一回合同样先整段输出 `disclaimer-preamble.md` 两段，不精简、不分层（精简分层在 backlog，未拍板前保持现状）。
- 免责声明每次输出末尾照带；敏感问题拒答、不替用户做决策等关键约束全部适用。
- 小白模式只改「问什么、先给什么、菜单长什么样」；**排盘命令、chart.txt、体检器、置信度传播等幕后链路与深度模式完全一致**。
