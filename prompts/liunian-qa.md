# 流年问答模式（直达通道）

> 触发：用户**直接问某一年的具体问题**——「我 2027 年适合跳槽吗」「明年运势怎么样」「今年适合买房/结婚/创业吗」「后年考试顺不顺」；也包括**月级问题**——「下半年怎么样」「这个月适合谈事吗」「几月适合换工作」（月级问题先归到所属年份，再落月级窗口作答）。
> 定位：轻量、单问单答。**不走 Step 0 长文菜单**，不出全套报告；答完即停，不诱导追问。用户若想看全盘，再引导进 Step 0。

## 流程（算法先行，严禁凭记忆推算）

1. **定年**：把「明年/后年/今年」换算成具体年份 `<Y>`（据系统当前日期）。
2. **排盘**：
   - 会话内已有该生辰的 `chart.json` → 用 `--currentYear=<Y>` **重跑** run-chart（运岁引动会以该年为当前年展开）；
   - 没有生辰 → 先按常规收生辰（公历/农历 + 时辰 + 性别），再跑。
   ```bash
   node <skill-root>/calculator/dist-bundle/run-chart.js --year=… --month=… --day=… --hour=… --minute=… --gender=… \
     --currentYear=<Y> [--lineage=<已选流派>] --output=<工作目录>/chart-<Y>.json
   node <skill-root>/calculator/dist-bundle/dump-text.js --input=<工作目录>/chart-<Y>.json --output=<工作目录>/chart-<Y>.txt
   ```
3. **取证据**（只从 `chart-<Y>.txt` 取，不得自创）：
   - 「大运」块 → 该年落在哪步大运、干支十神；
   - 「运岁引动」块 → 该年流年干支 × 原局/大运的全部命中（冲提纲/岁运并临/天克地冲/伏吟/凑局凑刑…）与权重；
   - 「流月引动」块（`--currentYear` 时算法层自动输出）→ 该年 12 个节气月的干支与逐月引动，**月级问题的唯一选窗依据**——不得凭记忆推流月干支或自创月内引动；
   - 「用神建议→出口」→ 喜忌五行，该年干支五行属喜属忌；
   - 「作用关系」裁决状态照抄立论，不得改判。
4. **作答**（结构固定，全程第二人称）：
   - **开头一行轻声明**（不出全文 disclaimer）：「先说明：这是传统命理视角的参考信号，不是预言——决定权始终在你。」
   - **定调锚点一行**：当前大运 + 喜忌五行（白话）。
   - **该年总评**：顺风/平路/逆风 + 程度词（强顺风/小逆风），给依据（流年五行喜忌 + 运岁引动命中，术语后白话）。
   - **对准问题域**：只深写用户问的事（跳槽→事业窗口与时机；买房→财帛与变动信号；结婚→婚恋引动），其他领域最多一句带过。
   - **可执行建议**：2~3 条具体动作（时机倾向、优先级、风险边界）。
   - **月级窗口**（用户问「下半年 / 这个月 / 几月适合…」时启用）：从「流月引动」块选窗作答——喜用五行当令且无重引动的月份为顺窗，忌神当令或冲刑集中的月份为需减速段；表述落到月级并**用农历月序＋公历对照**（如「窗口在农历七、八月更顺，大致对应公历 8 月上旬到 10 月上旬」，公历区间照抄块内日期）。一次点 2~3 个月即可，不逐月播报十二个月；月令只作窗口微调，**不得用流月推翻该年整体定调**。未问到月级、或 chart.txt 无「流月引动」块（未传 `--currentYear` 的旧盘）→ 保持整年粒度，不硬拆月份。
   - **置信度**：引动信号少或边界盘时明说「该年信号不强，参考权重放低」。

## 铁律（与主线同源）

- **顺逆措辞**：不用「凶/大凶/灾年」；逆风是需减速的路段，不是判决。
- **不替用户做决策**：给信号不给指令——「该年整体利变动、宜主动争取」可以，「你应该辞职」不行；重大决策（婚姻/大额投资/医疗）提醒结合现实条件判断。
- **可证伪事实护栏**：不断言用户现状（「你现在工作不顺」不行），用条件句（「如果你正觉得受限，那么…」）。
- **幕后台前分离**：引动权重、字段名、机制词不外露，只呈现结论。
- **答完即停**：不问「要不要再看看别的年份」；用户主动再问才继续。
