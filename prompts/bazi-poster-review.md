> 首遍负责「出稿」，本遍负责「捞底」——只重写**质量不达标的字段**，达标的**逐字保留**。专治「同一张海报里字段参差不齐」。
> 分工：JSON 合法性、字段计数、禁词、句式、timeline 白名单、着色存在性由 `check-analysis.js` 脚本查（若已跑，其 FAIL 字段直接进重生名单）；**语义质量（锚定/落地/口吻/护栏）脚本看不见，全靠本遍**。
> 本遍是「挑错」任务：求保守、求一致、不求生动。

## 输入
1. `chart.txt`（算法层文本盘，唯一事实源）
2. 首遍产出的完整 `analysis.json`
3. Step0 选定的流派
4. （若有）`check-analysis.js` 的体检报告——其 FAIL 字段免评审直接重生

## 铁律
1. **抬地板，不抬天花板**：达标字段逐字不动；目标是把最差字段拉到及格线，不是把好句子改花。
2. **重生必须回 `chart.txt` 重新锚定**：重写任一字段，盘面依据（干支/十神/宫位/神煞/作用状态/用神出口）从 `chart.txt` 重取，不得沿用首遍可能编错的引证，不得新增文本盘以外的神煞或干支。
3. **不串派、不改排盘**；**状态照抄**（合冲刑害【生效/减力/虚拱…】不得把「减力」写成「有力」）。
4. **算法注入适配**：`yongshen` 四格/divergence、`kaiyun` 用神/吉方/吉色/吉数/调候、大运流年配色均为**算法注入,不在评审范围**——只评 `yongshen.note_html` 与 `kaiyun` 的宜业/宜往/宜置/宜学/note_html。典出、核心看点、⏳引爆、流月条、护体档同属 `owner=algorithm`，**不要求提示词产出**；它们未出现在 `analysis.json` 不得判 FAIL，也不得为此重生字段。

## 第一步 · 逐字段评审（5 轴 + 类型红线）

**5 根通用轴（0=缺失 / 1=勉强 / 2=合格）**：任一红线踩中=FAIL；红线全过但 ≥2 轴 <2 = FAIL；否则 PASS。

| 轴 | 问自己 |
|---|---|
| A 锚定 | 有没有引具体盘面元素？还是换个盘也成立的通论？ |
| B 落地 | 每处结构证据后有没有**至少两倍篇幅**的现实意义，并说清「是什么／影响什么／怎么做」？ |
| C 口吻 | 全程第二人称「你」，无「命主/日主为」播报腔；术语是否当场翻成小白能懂的现实语言？ |
| D 护栏 | 有没有断言可当场证伪的行为/事实（婚否/职业/收入/胖瘦/熬夜/爱不爱运动）？ |
| E 规格 | 满足该字段形态规格（下述红线）？ |

**类型红线**：
- **判词**：7字或4+4对仗、有画面感偏积极、不堆格局术语。
- **两句类**（geju.sub/wuxing.note/yongshen.note）：恰两句，上句盘面、下句以白名单连接词开头（所以你/意味着你/这让你/落到你身上/这股劲让你/放到生活里；同海报各块宜错开）；`wuxing` 若出口含〔缺补说明〕未转述=FAIL；`yongshen.note` 边界盘未点明体用两分/分歧=FAIL。`dm.desc` 按日主固定句式（意象/特性是/意味着你/最强的能力/但）。
- **十神长段**：`tg.mech_html` 恰1句压缩主导/次要十神与关键生克链；`tg.plain_html` 须 **≥6句、≥200字、不设上限**，完整覆盖能力与需求、决策/协作/工作中的至少两个现实场景、帮助/代价和1~2个动作；一句白话、只解释术语、或正向语义未逐处标绿=FAIL。
- **四大段落**：每段须 **≥6 句、≥200 字、不设上限**；删掉括号内术语后仍要完整可读，并按「白话结论→现实表现→帮助/代价→具体动作」闭环；只有「把握机会/注意沟通/保持健康」而没有动作=FAIL。**所有正向或偏正向判断都须逐处用完整的 `<span class="hl-good">…</span>` 标成绿色粗体，每段至少 3 处只是机器底线，不是达标目标**；优势、能力、可靠、人缘、适配方向、助力、顺风窗口、上行阶段、改善与收益结果有任意一处仍是普通字=FAIL。正负混合句必须拆成绿/红两段，不能只标风险、漏掉同句优点；零星单词、只用 `<strong>`、选择性挑亮几句都=FAIL。`career` 财路叙事必须对照 chart.txt 十神结构（默认"才华生财"未核食伤生财链=FAIL）；career 若展开进财性质（经营/博弈轴），性质须与盘面财星正偏主导一致（正财主导写成机会博弈型、偏财主导写成守成经营型=FAIL；财无明现不展开性质轴、或只走主链路不提性质，均不算 FAIL）；`marriage` 必含正缘画像**四型分型句式**（锚头按「正缘倾向.宫坐」：印星→你适合的另一半/官杀→能接住你的/财星→让你眼睛一亮又留得住的/食伤比劫→与你最同频的；锚头与宫坐不符=FAIL）+整句标绿+紧跟"TA 会怎么对待你"，年龄择一或明确改用性格轴（骑墙=FAIL）。
- **正向着色扫漏红线（所有解读字段）**：评审每个字段时，先临时删除所有 `<span class="hl-good">…</span>` 及其中内容，再读剩余可见文字；只要还能找到一句在夸优点、说明适合、提供助力、预告顺风/上行，或描述某个做法的正向收益，该字段立即 FAIL 并重生。特别检查「但/同时/因此/更容易/适合」两侧，防止只标一句中的一半。纯盘面证据和不含评价/收益的动作指令可以不着色。
- **小白直读红线**：以术语开场、出现术语却不解释、把盘面证据当结论、用户读完仍不知道现实影响或下一步动作，任一项命中即 FAIL。性格需落到决策/压力/协作至少两项；事业需落到工作环境/赚钱方式/合作边界至少两项；婚恋需落到表达爱/冲突处理/伴侣画像至少两项；健康需从作息/运动/饮食/体检中给至少两类动作。
- **三个精读段**：3~7句讲真正生效/最要紧的2~4项；状态照算法层；`yunsui` 只讲今年起5年+当前大运；顺逆措辞（出现「凶/大凶/灾年」=FAIL）；`shensha` 露出 via/tier/needs_review=FAIL、须按三段式（等级→主什么→意味着你什么加粗）。
- **罕见现象**：chart.txt 有「罕象」时，`rare.reading_html` 必须 **≥4句、≥160字、不设上限**，按原序逐项点名且明确写「偏正向／偏提醒／两面性」，再翻成现实可观察现象和行动；把“罕见”直接等同“吉/凶”、只抄算法说明、漏项或没有现实映射=FAIL。chart.txt 无罕象时必须为空字符串，模板整块隐藏。
- **短标签**（kaiyun.ye/place/item/skill、timeline[].desc）：具体不空泛、以出口开运用神/喜神为锚；timeline 年/岁必须取自「运岁引动→建议节点」白名单、重级节点若存在必须入选、措辞顺逆化。

产出一张**内部评审表**（不进最终 JSON）：逐字段 PASS/FAIL + FAIL 一句话病因（指名踩了哪条轴/红线）。

## 第二步 · 只重生 FAIL 字段
1. 回 `chart.txt` 取回该字段应有依据（1~3 条具体引证）；
2. 按类型规格重写，对症下药：缺锚补干支宫位；缺落地把意义写到两倍篇幅；踩护栏按句式转换表；骑墙择一；
3. 自查：病因消除？无新红线？删掉括号内术语后是否仍能看懂并照做？未误改他字段？

**护栏句式转换表（照抄执行）**：
- ✗「你不太爱动」→ ✓「你的体质需要靠规律有氧把郁结代谢出去——**无论你现在动得多少**，这件事对你的回报都比常人高」
- ✗「你习惯熬夜」→ ✓「熬夜对你的损耗比常人更大，值得优先守住作息」
- ✗「你不善表达」→ ✓「你的表达欲偏内收，熟悉场合才充分释放」

## 输出契约
