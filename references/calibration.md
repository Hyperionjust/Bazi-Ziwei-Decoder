# 校准与回测（三类，别混着做）

> 这三类的**金标来源不同、评分方式不同、能证明的东西也不同**。混进一个流程会互相污染，
> 最常见的后果是：拿 B 类的命中率去证明 A 类的实现对了。

### 为什么调候表没有逐格断言

拿到可确证的底本之前，逐格断言「原文就该是甲庚」是**伪金标**——只会把一次未经核对的抽取固化成"标准答案"。三个原因：

1. **文本系统不唯一**：《栏江网》→ 余春台辑本 → 徐乐吾评注本，各本有异。
2. **原文不是表**：原文是散文式论述（「正月甲木，初春犹有余寒，得丙癸透…」），压成 `["丙","癸"]` 这一步本身带编辑判断。所谓"逐格对原文"实际是**复核一次抽取**，不是抄写比对。
3. **网络电子版转录错误率高**，不作为底本采信。

所以 `test-tiaohou.ts` 只断言**不依赖版本也成立**的东西：结构完整性、快照锁、寒暖燥湿宏观不变式、接线一致性。

### 条例层的校准怎么做（v3.11.0 M1 起）

「吸收」和「校对」是两件事。校对只回答「取干列表抄没抄错」；**吸收**要把每格背后那棵条件树搬进算法——
「一派庚辛」「支成水局戊透为贵」这些分支是**盘面可判的确定性事实**，不是取用口味问题。所以条例层能做的校准比取干层强一档：

| 断言 | 依赖底本吗 | 现状 |
|---|---|---|
| 每条 `若` 在受控词表内且可被求值器解析 | 否 | `test-tiaohou.ts` ⓑ，违例即 FAIL |
| **每条 `则` 是本格 `原文` 的连续子串** | 否 | `test-tiaohou.ts` ⓒ——这是「层2 照录不改写」的机器护栏。吸收 ≠ 转述 |
| 求值器对给定盘的命中/落空 | 否 | `test-tiaohou.ts` ⓓ，7 个手工盘，正例与反例都断言 |
| 条例快照锁 | 否 | `test-tiaohou.ts` ⓔ，与取干表同规格 |
| 无死条例 / 无恒真条例 | 否 | `test-tiaohou.ts` ⓕ，每格 4000 随机盘。两头都要堵，见下 |
| `关系`/`蕴含` 与实际命中集合一致 | 否 | `test-tiaohou.ts` ⓖ + `fixtures/bless-tiaoli-relations.ts` |
| 条例内容本身对不对 | **是** | 仍是【待核】。两系有异文的一律并存标 `两系分歧`，不择一 |

**⚠ ⓒ 这道网防不了什么，说清楚**：`则` 只跟同一个 JSON 里手写的 `原文` 比，是自洽的循环。
它能防「抄进来之后被改写」，**防不住「抄的时候就抄错」**——后者只能靠人工把 `原文` 对素材原书。
M1 已把甲行 110 条逐条对过 `素材/穷通宝鉴.pdf` 的文本层：**109/110 逐字连续命中**，
唯一例外是 `甲/寅` 的「得丙癸**透**」（PDF 文本层作「逢」），有李铁笔影印本书页 72 背书，已在校勘块登记为电子本讹字。
后续批次必须重复这一步，不能以为 ⓒ 通过就等于抄对了。

**M4 收官后全表机器复核（2026-07-30，程序化，独立于各批自查）**：把 120 格的每段 `原文`
与全部 1396 条 `则` 归一化后逐一回比 `素材/穷通宝鉴.pdf` 文本层，两个结论：

- **「则」1388/1396 逐字连续命中**。8 条不中者全部对应**已登记的校勘改字**，零静默偏离：

**月令藏干两头都是坑（M1 实战教训）**：月支的藏干是恒定的——寅恒藏丙戊、辰恒藏癸、巳恒藏庚、申恒藏庚壬戊、午恒藏丁、戌恒藏戊。

- 把典籍的「无丙」照字面写成全盘 `无:丙`，在寅月**永远为假** → **死条例**，一条谁也不知道已经死了的规则。M1 首审抓出 7 条。
- 把「须见戊土」写成 `有:戊`，在申月**永远为真** → **恒真条例**，典籍写的条件等于没判。M1 抓出 1 条（`甲申-壬无碍见戊`），另有 8 处合取项形同虚设。

两者一律按【天干透出】判，并在该条例的 `判定备注` 里写清为什么偏离字面。ⓕ 审计两头都查。

**「成派」阈值须单独说明**：典籍只说「一派庚辛」，没给判据。我们取「该五行含藏干加权分 ≥3.0 且至少一字透干」
（天干每字 1、地支本气 1、中气 0.5、余气 0.3，与 `countWuXing.withCangGan` 同口径）。
这是**我方的操作化定义，不是典籍原文**，命中时一并输出加权分以便审计；改阈值 = 改词表版本。

### 底本归属：先决问题

**《穷通宝鉴》和《造化元钥》不是一本书的两个名字，是同一祖本的两个流传分支，有实质内容差异。**
在决定核哪一本之前，逐格校勘无从谈起。据公开检索所得的源流（**此说本身亦待底本佐证**）：

```
《栏江网》(民间流传)
   └─ 清康熙·避讳改名 →《造化元钥》
         ├─ 清光绪·余春台整理刊行 →《穷通宝鉴》
         │     └─ 民国26年(1937)通行本：讹误甚多（有「南」抄作「西」一类字误的记载）
         └─ 民国28年(1939)·徐乐吾据精校本作注，仍名《造化元钥》→ 一般认为准确率更高
               └─《造化元钥评注》：成稿未及出版即离世 → 手抄本流传
                     → 韦千里校定，丙午年(1966)刊行
                        → 现代重印本（如梁湘润编·宏业精印本，检索到 ISBN 9786523266832）
```

**已知争议**：有论者指徐乐吾《造化元钥评注》混订两系而未加区分，举的例子正是「正月甲木」——
也就是我们表里的 `甲/寅`。所以那一格现在是**优先级最高的待核疑点**：它是判别本表整体属于哪个文本系统的标志格。

> 注意：百科、问答、书店页面只能提供**版本信息**（出版社/ISBN/年份），**不能提供可核的原文**。
> 它们帮助定义"该找哪一本"，不能替代那一本。

### 校勘分两级

| 级别 | 标准 | 能做什么 |
|---|---|---|
| **底本** | 有书名/编注者/出版社/版次/页码的可确证版本（影印本优先） | 可定案；全表核完后 `底本.状态` 才能改为 `已确证` |
| **佐证** | 可交叉核对但达不到底本标准的文献（现代重排本、摘编本、无版本信息的电子本） | **只能解除疑点，不能单独定案**。`test-tiaohou.ts` 会强制：已核格全为佐证级时，底本状态必须仍是「未确证」 |

### 怎么把某一格从「待核」变「已核」

在 `tiaohou.json` 的 `校勘.已核` 里加一条：

```json
"丁/寅": {
  "取干": ["甲", "庚"],
  "原文": "非庚不能劈甲,非甲不能引丁",
  "出处": "《穷通宝鉴》丁火篇（书名/编注者/出版社/版次/页码）",
  "状态": "已核"
}
```

`原文` 与 `出处` 都不能为空——`test-tiaohou.ts` 会检查。全表核完后把 `底本.状态` 改成 `已确证`。

**「行内重复度」三条疑点结案（v3.11.0 M2/M3）：非错，且判据是结构性的。**
逐月条各自成文、各自给理由，**次序随各月的理由变动** —— 丁行二月「湿乙伤丁，**先庚後甲**」是倒序、五月壬庚癸、六月甲壬庚 自成一格；
戊行更硬：**只有「三春戊土」一段总论**，四月到十二月根本没有三夏/三秋/三冬总纲，「套用总纲」在九个格上不可能，没有可套的纲。
**「仅 4 种取法」是把有序三元组归并成无序集合后的统计假象** —— 按字面次序戊行实为 8 种。
文献缺口另记：`丁/丑`、`乙/丑` 两系皆无十二月专条（不是抽取遗漏）。

**已解除**（累计 5 项）：
- `庚/未`（丁甲）——「土旺金顽，故先用丁火，次取甲木」，夏月不取水有典据。
- `甲/寅`（丙癸）——**双源一致**：李铁笔影印本书页 72 与知砚斋本同文「得丙癸透，富贵双全，癸藏丙透，名寒木向阳」。两系分歧传言在此两份文献间不成立。
- `丁/巳`（甲庚）——「必用庚劈甲…癸水一见，泄庚、湿甲、伤丁，故以癸为病」。癸在此格是病不是药，寒暖不变式的例外有典据。
- `己/未`（癸丙）——「三夏己土…取癸为要，次用丙火。无癸曰旱田，无丙曰孤阴」。此前的"壬庚分歧"是抽取错误，收回。
- `丁/午`（壬庚癸）——「庚壬两透者科甲定然…得一癸透名独杀当权」，三干全有据。

> 注意：丙火行同样以壬贯穿全年，但那是有典据的（「丙火猛烈，专用壬水」）。丁/戊/己 三行是否同理，
> 必须由底本决定，**不能因为"看起来重复"就判为错**。

## B 类 · 现实事件盘（只当哨兵，不当指标）

按时辰可靠度分三层，不要混用：

| 层级 | 来源 | 说明 |
|---|---|---|
| Tier 1 | Astro-Databank **AA 级** | Rodden Rating 的 AA = 有出生证明/出生记录，是唯一能批量拿到证件级时辰的来源。人物多为西方人，八字照排（timeZone 给对即可），恰好绕开中文名人盘"时辰全靠传抄"的通病 |
| Tier 2 | 正史 / 起居注 | 如清代帝王（《清实录》记生辰时刻）。误差来源在"古代时刻→现代时制"的换算，不在记载本身 |
| Tier 3 | 传抄 | 蒋介石、曾国藩、孙中山这类，各家说法不一。**能用，但必须标 `time_source: 推测`，只作弱参考** |

`time_source` 与 Rodden Rating 的映射：AA→证件/记录、A→本人确认、B→家人回忆、C/DD→推测。

**这一类能证明什么：** 只能发现"重大晋升年被判逆""终局年被判顺"这种**系统性反向**。
**不能证明什么：** 任何形式的准确率。理由见 C 类。

## C 类 · 对照组（不做，B 类的数字就没有意义）

1. **随机盘对照** —— 同一份事件年表配到 N 张随机盘上跑同样的对账。真盘命中率若与随机盘无显著差异，说明当前判定规则对该类事件没有信号。**这是唯一能把"命中率 50%"与"抛硬币"区分开的办法。**
2. **同盘不同命** —— 双胞胎，或同年同月同日同时辰的两个普通人。标定"盘能解释多少"的上限，直接决定工具措辞该多保守。
3. **盲测** —— 评分者不知道哪张是真盘。现在 `run-calibration.ts` 是"排盘 → 人工评分"，很容易在知道答案的情况下打分。

## 韦千里《批命104例》——B/A 混合型命例源（评估结论）

素材里的《批命104例》（72 页文本版）体例已核实：**每例 = 名人命造 + 四柱 + 大运排列（起运岁数）+ 用神断语 + 应期断语**。
实测：四柱串 99 个、大运年龄标记 107 处、命中人物含 马占山/吴佩孚/阎锡山/杜月笙/宋子文/段祺瑞/虞洽卿/许世英 等。

它的价值是**双重金标**，两条都比此前的单盘回测强：

1. **A 类用法（主推）**：书里白纸黑字给了「病于水盛」「妙有丁火煦融」这类**用神判定**——
   拿命例四柱跑我们的算法层，对照韦千里的取用结论。这验的是"我们的旺衰/用神线与民国专业命理师的判定是否一致"，
   金标是书上的字，可证伪，不涉及预测效力。
2. **B 类用法（辅）**：命主全是有史可查的民国人物，断语里还有应期（「行届未运…再逢辛未之年，宜乎一鸣惊人」），
   可与史实年表对照。但时辰均属传抄级（`time_source: 推测`），只作哨兵。

**落地格式**：转成 `fixtures/calibration/classics/*.case.json`，`case_type: 典籍判定`——此类不含在世者隐私（民国公众人物、出版物内容），
