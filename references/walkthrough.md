# 一次完整对话的走法示例

**用户**：我是 2000 年 1 月 1 日 12:00 出生的男生，帮我看下命盘。

**Skill 应该走**：

1. **信息确认**：日期 / 时辰 / 性别齐 ✅（出生地可选，不主动追问）
2. **启动版本检查**：静默跑一次 `version-check.js`（只比对远端 VERSION，不下载不执行），无更新就什么都不说
3. **阅读方式先行**：用户尚未明确偏好时，第一句先问「想看通俗易懂的结果，还是专业细节更完整的详解？」
   - 选通俗 → 走小白模式，保留用户已说清的类型/形态，其余按默认补齐
   - 选详细 → 再进入标准三项决策门，一条消息问齐缺项——"要看八字 / 紫微 / 综合印证？八字可选流派镜片；呈现上强烈推荐先聊天详细分析，看懂后再考虑海报"
   - 用户若说"都听你的" → 按默认（八字独立 + 不限流派 + 长文）开工并声明默认项
   - 用户若露新手信号 → 直接使用「通俗结果 / 专业详解」这一问，不再问「全面了解还是具体问题」
   - 用户若直接问某一年 → 走流年问答直达通道，答完即停
4. 用户回"八字，子平派，先聊天"：
   - **Step 1**：`run-chart.js --lineage=ziping` → `chart.json`
   - **Step 1.5**：看 `时辰边界.boundary`——为 true 则先核盘再解读，本例 12:00 不临界，跳过
   - **Step 2**：`dump-text.js` → `chart.txt`
   - **Step 3a**：先输出 `disclaimer-preamble.md` 的两个短段与一行免责声明，随后立刻按 `bazi-prompt.md` + `output-mode-B.md` 写【底色 / 长板 / 提醒 / 阶段】四句核心结论
   - **后置体检**：长文存 `report.md` 后跑 `check-analysis.js --mode=longform`，FAIL 自行改写再交付
5. 首回合用三个加粗小段分组列出 11 章入口，不再列三行交付状态。若用户同时要海报，默认写成一个短段：`对话先聊 / 海报待看完后确认生成`；用户明确要求现在都生成时才同轮出图
6. 用户回"详细展开第 3 章" → 只深写该章，顶部复述定调锚点
7. 收尾给使用指引："对任何一句有疑惑可直接把原句发来；想深挖就回复章号。"

## 常见岔路

- **三项没问齐就排盘** —— 最常见的违规。生辰齐全 ≠ 三项已选。
- **一次性下灌全文** —— 除非用户在 Step 0 选了"完整报告"，否则只出速览。
- **注意事项和目录挡住解读** —— 开头只有两段短声明；随后必须立刻进入四句本人结论。下钻优先用“加粗要点 + 小段落”，不要连续堆 bullet list。
- **把 11 章菜单说成已生成的详解** —— 11 章只是展开入口；未点章前章节正文不存在。
- **海报顶部看不到八字本体，或一上来铺满专业盘面** —— 八字海报总领先显示紧凑的年、月、日、时四柱核心条并突出日柱，再显示与正文 01~08 一一对应的八项人生坐标；藏干、十神、旺衰和大运表等完整详表仍放在“专业依据”分隔线之后。
- **把机制说给用户听** —— 置信度档、边界字段、体检流程都是幕后，只出白话结论。
